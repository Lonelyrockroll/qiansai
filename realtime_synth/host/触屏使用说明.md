## 每次怎么用

1. 屏幕 HDMI 仍接 Tang，屏幕一个 Touch Micro-USB 用数据线接这台电脑；Tang DEBUG-USB2 也接电脑。保留当前已经验证工作的供电和 J13/J11 接线。
2. Tang 核心板启动后，临时下载 `../control_display/impl/pnr/synth_display.fs`，或运行该目录的 `download_sram.ps1`。当前版本 **v12 / User Code 0x0000BF36**。本次没有写 Flash，断电后需要重新临时下载。
3. 打开上位机并连接 COM6，在“7 英寸成品屏”区域点击 **“启动触屏 · 电脑转发”**。
4. 保持电脑上的 **“Tang 设备控制接收 — Esc 停止并静音”** 接收窗口在前台。若未自动置前，点击该窗口或从任务栏选中它；确认触摸输入已启用且设备已连接。
5. 在 7 英寸屏幕右侧菜单轻点并松手，即执行相应功能，不用先移动高亮。进入检测图后，轻点画面任意位置返回。
6. 电脑按 **Esc** 退出接收并静音；或在上位机点击“停止触屏并静音”。切到其他电脑窗口会暂停转发并静音，回到接收窗口后先松开手指再操作。

实体演奏顺序仍是 **切换扫描 → 全部松键，等待校准完成 → 开始演奏**。触摸左侧钢琴图暂不发声，该区域只显示实体琴键状态；本版为单指菜单控制。音量以约 2 个百分点调整，作用于后续实体音符，实体力度上限 25%。屏幕参数为当前实体参数；上位机原音色/力度设置用于发送新的设置，应用实体输入设置会覆盖菜单参数并重新校准。

## 已实现与边界

- 屏幕枚举为 USB HID 触摸屏 `0483:5750`，Report ID 1、11 字节输入报告、X=0～1024、Y=0～600。触摸模块使用 Windows Raw Input 和 HID 官方解析接口，仅解析指定触摸设备；v12 另有控制键盘模块，仅映射 `1189:8840`，普通电脑键鼠不映射为合成器控制。没有安装替代驱动。
- 用户的两角实测确认方向正常，直接按 HID 逻辑范围映射到 1024×600。首次日志包含拖动和重复释放，按 Hybrid HID 的完整联系点帧解析，不能将 Contact Count 直接等同于正在按下的手指数。
- 一次轻点在松手时执行一次；移动超过 24 像素、跨按钮、长按超过 2 秒、多指操作、失焦或过期数据不执行。菜单之间的空隙不作为按钮。
- 接收窗口失焦/退出、触摸设备拔出或接收心跳中断会静音。电脑触摸开启的演奏保留 FPGA 通信看门狗，区别于板载按键启动的独立演奏。
- 音频合成、钢琴音色、ADC 扫描和屏幕渲染仍由 FPGA 完成。电脑只解析 USB 触摸、判断菜单位置并转发控制命令。
- **本版需要电脑运行转发程序；FPGA 直接连接 USB 触摸屏的独立 USB Host 尚未实现。**

## 文件和验证

`touch_hid.py` 读取并解析指定触摸设备；`touch_logic.py` 拼装联系点帧并判断轻点；`touch_bridge.py` 提供接收窗口并转发；`server.py` 保持唯一串口连接和心跳。

固件 opcode 10 的 payload `[5, 菜单编号0～7]` 可原子执行指定菜单。v11 增加了该命令，并区分电脑与板载按键发起的演奏会话；旧的 opcode 1～11 布局保持兼容。

测试包括：10 项上位机测试（含实际 420 份 HID 诊断报告回放）；29 条菜单 UART RTL 请求（含直接菜单、非法编号、电脑心跳超时）；25 条原串口/音频和 18 条键盘系统回归。日志、真实触摸菜单回读和用户反馈见 `../control_display/touch_validation/`。

v10 备份位于 `../versions/v10_before_usb_touch_20261026/`，v11 备份位于 `../versions/v11_before_keypad_20261027/`。v11 当时的合成域 Fmax 为 50.004 MHz；当前 v12 为 50.016 MHz，均无 Setup/Hold 违例，50 MHz 目标余量仍很小、PR1014 保留。显示布局、原音色算法及接线未变。
