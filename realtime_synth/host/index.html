32 键灯光

连接 v17 固件后可控制灯光

测试先全灭 1 秒，再逐颗点亮，每颗约 0.3 秒，完成后自动全灭。亮度固定为 8/255；琴键跟随需先开启扫描、完成松键校准并开始演奏。按旋钮 A 静音也会关闭灯光。

数据线电平诊断 · 万用表

黑表笔接键盘 GND，红表笔接 D1 的 DIN。每次最多保持 30 秒，随后自动恢复全灭数据；这里只测试数据脚，不给灯供电。

建议测试顺序

1. 连接板卡，确认采样帧持续增加。

2. 按虚拟琴键，观察门控与活跃声部。

3. 保持音符，切换音色、调节力度。

4. 用四声部和弦检查复音。

5. 使用 32 声部测试，配合示波器或音频采集查看频谱。

安卓手机第一次连接
  1. 手机「设置 → 蓝牙」选择 =BTNU1（地址末尾 7BB6），输入这块 JDY-31 的配对码。
  2. 打开「蓝牙调试宝」或 Serial Bluetooth Terminal，允许访问附近设备，在经典蓝牙（Classic / SPP）列表中点 =BTNU1 连接。
  3. 选择文本收发，关闭 HEX。先单独发 UUUU，然后单独发英文 ?。收到 OK V… T… F… 就表示板卡已回复。B 是 FPGA 测得的位宽，网页会显示换算后的速率。
