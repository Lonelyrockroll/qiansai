# 三种音色的同条件试听

试听顺序为原 v26 钢琴、上一次用于频谱演示的 32 分量音色、本次调整的 32 分量钢琴。三段来自同一组音符，采用相同力度、时长、触键和导出增益。这里运行了原 v26 的实际 Verilog 内核，两个 32 分量版本则各自使用实际的系数 ROM 和模态内核。

- [C4 单音对照](C4_compare.wav) 每段按住 C4 约 0.49 秒再松开，三段之间各留 0.25 秒。
- [三段乐句对照](phrase_compare.wav) 每段依次弹 C4、E4、G4、C 大三和弦，再弹 C6。
- [单独听新的钢琴](musical32_phrase.wav)。

三种音色输入力度都是 16384（约 25%），输出统一乘 2，没有分别归一化音量。乐句的和弦由各音的真实内核输出线性相加，模拟功放、音箱、整机限幅和空间效果均不在此试听链中。控制台或开发板上的实测另行记录。

## 频谱与动态

表中“重心”按功率加权，“高频占比”指 4 kHz 以上能量占窗内总能量的分贝值。早窗为按键后约 5～47 ms，晚窗为 221～305 ms。

| 测量项目 | 原 v26 | 旧 32 分量演示 | 新 32 分量钢琴 |
|---|---:|---:|---:|
| C4，早窗谱重心 | 490 Hz | 1361 Hz | 495 Hz |
| C4，晚窗谱重心 | 435 Hz | 1319 Hz | 450 Hz |
| C4，早窗高频占比 | −68.3 dB | −11.5 dB | −30.7 dB |
| C4，晚窗高频占比 | −66.9 dB | −12.0 dB | −39.4 dB |
| C6，早窗谱重心 | 1931 Hz | 4644 Hz | 1944 Hz |
| C6，晚窗谱重心 | 1773 Hz | 4731 Hz | 1660 Hz |

在前 2048 帧内统计各分量的非零实际乘积。新钢琴的 C4、E4、G4 各有 32 个有贡献的分量；C6 在合成带宽内有 19 个。三版导出都没有数字削波。新版乐句的峰值为 17,270（满量程 32,767）。[全部数据](result.json)

运行 `python render.py --render original_v26 bright_demo32 musical32 --analyze` 可重新生成试听。缓存按 RTL 源文件和原始 PCM 的 SHA-256 核对。运算间隔省略空闲时钟，每个音频采样的相位、衰减和瞬态均由实际 RTL 更新，工程采样率为 48,828.125 Hz，WAV 文件采样率取可表示的整数 48,828 Hz。
