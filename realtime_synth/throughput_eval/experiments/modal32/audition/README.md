# C4 · 16/32 分量试听

播放 `C4_AB_16_then_32.wav`。先听前 16 分量，再听全部 32 分量，两遍之间留 0.20 秒空白。也可分别打开 `C4_16_components.wav`、`C4_32_components.wav`。A 用候选音色的前 16 个分量；v26 原钢琴音色是另一套模态参数。

素材来自模态内核实际 RTL 的 `done/sample` 输出。两次都触发 C4，起音力度 16384，DDS 步进、相位种子、锤击瞬态和包络相同，第 50,000 帧松键，每段共 60,000 帧。导出时给两段都乘 4，未独立调整响度。播放采样率使用 WAV 可表示的整数 48,828 Hz；内核标称 48,828.125 Hz。

运行 `python render.py` 可重新产生 WAV 并回读校验。脚本编译真实 `../modal32.v`、`../modal32_coeffs.v` 和既有正弦 ROM。测试台只缩短两次计算之间的空闲时间，没有用解析模型生成音频。此试听不包含整机效果器、音频输出模拟链或扬声器。
