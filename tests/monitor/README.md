# FPGA 本地音频观察页

屏幕从送往 DAC 的同一条 16 位单声道 PCM 总线取样。三块图都由 FPGA 实时生成。手机、蓝牙与电脑不参与观察页计算。原生音频采样率为 50 MHz / 1024，即 48,828.125 Hz。

- **波形**显示滚动窗口中的 64 个采样点，每 8 个音频样本取一个，屏宽约 10.49 ms。显示增益随上一分析窗的最大绝对值调整，只改变图的缩放。
- **频谱**显示 1024 样本矩形窗的 64 个连续 DFT 频点。频点间隔为 47.6837158 Hz，图上从 47.68 Hz 到 3051.76 Hz。真实采样与每个频率的正弦、余弦分别相关。一只乘法器在每个音频样本期间分时完成 128 项运算。累加器保留 25 位。柱高使用相对对数刻度，幅值近似为两路绝对值的较大值加上较小值的一半。
- **延时相图**的横轴是当前 PCM，纵轴是同一单声道的第 16 个历史样本，延时约 0.328 ms。每个窗口累积 16×16 个轨迹格。正弦输入形成 1:1 李萨如轨迹；以 762.94 Hz 输入，延时正好四分之一周期，可形成近似圆形。自然音、和弦和打击音会形成不同的轨迹。

进入“音频观察”后，LIVE 页的 **LAST I2S** 显示最近一次有效孤立琴键事件的 I2S 起音计时，单位为微秒。尚无有效记录时显示短横线；后续非孤立事件保留上次有效数值。短按 B 在 LIVE、32 音测试、31 音测试间切换。Loop 正在播放、录制或等待录制时，页首显示 **LIVE / STOP LOOP FIRST**，继续展示实际 PCM，测试音的目标刻度隐藏。测试期间转动 B 可以换一条缺失声部。琥珀色刻度标出测试音的目标位置，红色刻度标出选定缺失位置，蓝色柱才是 PCM 测得的频带强度。A 点按静音退出，LIVE 时转动 B 也可退出。

测试音落在第 1、3、5…63 个频点，中间各留一个空频点。PEAKS 数字根据柱形的严格局部极大值计算，须高于绝对门限，并与上一完整窗主峰相差约 18 dB 以内。它与发生器设定的声部数分别计算。单音的自然谐波也可能形成多个峰，因此评委员可切到稳定的独立正弦测试音，再观察去掉某一音时对应峰消失。正常演奏中的峰数不能直接换算为独立振荡器数。

观察页以约 21 ms 为一扇分析窗，I2S 起音时间由单独的事件计时器提供。数据经握手在视频消隐期间锁存，直到下一帧才换图。每一组波形、频谱及相图帧是在同一分析窗完成后拷贝到未显示的 RAM 银行。像素域在视频消隐时锁存发布的银行，系统域收到显示确认后才可重用另一银行。该页主要展示钢琴基音范围和现场测试频点。C4 的第 32 分量在约 8.37 kHz，超出本页频带，应查阅对应的完整 PCM 频谱实测记录。

## 回归

从工程根目录运行 `python tests/monitor/run.py --native --render`。需要 Icarus Verilog、Python 3 和 Pillow。该命令按每 1024 个系统时钟一个 PCM 样本驱动生产 RTL。连续输入静音、单音、双音、32 个奇数频点、关闭第 10 路的 31 音和静音。每组运行两扇分析窗。

独立参考逐点检查波形与延时轨迹，并核对频率选择性、峰数、无运算超时、跨时钟域帧锁存。六组分别测得 0、1、2、32、31、0 个峰。`results/tone.png`、`results/test32.png`、`results/test31.png` 为实际 RGB RTL 仿真输出。图中的 00627 µs 是测试平台向 renderer 注入的时标，用于检验数字显示，不能作为实板延迟测量值。`validation.json` 记录源码散列和所有频点的实测柱高。


单独执行 `python tests/monitor/run.py --banks-only` 可检查银行所有权，结果见 `results/bank-validation.json`。原生命令也包含此项检查。已有 RGB 黄金图时，`--render` 会逐像素比对三张图。`results/pixel-comparison.json` 记录双银行初版相对宽快照版的对照；LIVE 页后续的 LAST I2S 标签变更单独记录在 `results/last-i2s-label.json`。整机布局请查仓库 `firmware/contest32-build.json`。

执行 `python tests/monitor/run.py --status-only --render` 可单独检查 LIVE、Loop 阻塞和 32/31 测试标题、旋转提示及目标标记的最终 RGB。`results/loop-header.png` 是 Loop 阻塞状态的真实 RTL 标题条。
