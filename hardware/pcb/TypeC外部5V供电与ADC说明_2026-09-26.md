# 32 键单灯：Type-C 外部 5V 供电版

交付文件：`nos_pico_32key_TypeC5V_1LED_ADC_2026-09-26.eprj2`。EDA 工程名：`nos_pico_32key_TypeC5V_final`。这是嘉立创 EDA 专业版原生本地工程文件，使用“文件 → 打开工程”直接打开，无须作为 epro2 导入。原生文件包含已保存的布线、铺铜和器件库历史。

本版在 2026-09-25 的 32 键单灯版本上新增独立 Type-C 供电。琴键、霍尔和灯珠的位置不变，板框仍为 412×64mm、键距 12.5mm。Type-C 沿用原 28 键板左侧接口的位置和封装。

## 电源与控制连接

```text
支持 Type-C 5V/3A 输出的电源
        │ USB-C 线
        ▼
USB1 VBUS ── F1 保险丝 ── 键盘 +5V ── 32 颗 LED、32 个霍尔、ADG732
USB1 GND ───────────────── 键盘 GND ── Tang GND

Tang 按开发板原有方式供电；两板之间连接控制信号、模拟输出和 GND。
原键盘 U1.19 已改为空脚，不再连接键盘 +5V，也不能用来给键盘供电。
```

- Type-C 仅供电，D+/D−、SBU 不连接；不提供 USB MIDI、USB 数据通信或固件下载。
- CC1、CC2 分别通过 R3、R4（5.1kΩ，1%）接地，支持 Type-C 插头正反插。
- 这是固定 5V 输入，不带 PD 高压请求或降压电路。不能输入 9V、12V、20V。
- 必须使用支持 **Type-C 5V/3A 电流档位**的电源及合格的 C-to-C 线。本板没有 CC 电流档位检测和自动限载功能，不能把“有 Type-C 接口”理解成任何电脑口、扩展坞或充电器都可提供 3A。PD 充电器能否使用取决于其 5V 档位能力。
- U1/U5 的 GND 与 Tang 共地。ADC_OUT 与地线成对、尽量短，避免 LED 的供电回流经过细长模拟参考地线。
- 两板应在供电稳定后进行信号交互。此版断开了 5V 电源直连，但没有增加所有数字/模拟信号的掉电隔离；不要在 Tang 未上电时让键盘模拟输出长时间驱动其输入，也不要在键盘断电时持续驱动其控制端。

Type-C 下拉与电流档位依据：[Renesas USB Type-C 电源角色说明](https://www.renesas.com/en/support/engineer-school/usb-power-delivery-03)。5.1kΩ 下拉用于声明用电设备身份，不会强制电源提供 3A。

## 新增或变更的器件

| 位号 | 规格 | 用途 |
|---|---|---|
| USB1 | 沿用原 Type-C 接口封装；原 BOM 为 U262-161N-4BVC11 / C319148 | 外部 5V 输入 |
| R3、R4 | 5.1kΩ，1%，0603 | 两个独立 CC 下拉 |
| F1 | Littelfuse 046702.5NRHF，2.5A/32V，0603 快断保险丝 | 输入过流后备保护 |
| C69 | 2.2µF，16V，X7R，0603 | 输入附近去耦 |
| R1 | 10kΩ，1%，0603 | ADC 分压上臂 |
| R2 | 2kΩ，1%，0603 | ADC 分压下臂 |
| C30 | 不装，BOM 已标记排除 | 避免未经验证的 1nF 滤波增加扫描建立时间 |

F1 采用项目内的 0603 手焊焊盘，并添加独立保险丝符号与器件型号。保险丝不是精密的 2.5A 恒流限流器；应配合本身具有短路/过载保护的稳压电源使用。其连续工作电流需要温度降额，依据 [Littelfuse 467 数据手册](https://www.littelfuse.com/assetdocs/fuse-467-datasheet?assetguid=4a59f034-1cca-460e-a5ba-e1e66247c76d)。

原 1A 二极管 D63、旧升压接口 U3 和供电焊桥 JP1 不恢复。Type-C 插座本身有防反插结构，本版未增加独立的反接 MOSFET 或主动过压断开器，保险丝不能替代这些功能。

接口沿用原工程封装，新增 0603 元件采用既有焊盘。采购、贴片前仍需以实际厂家尺寸和引脚定义核对料号，不能根据相似的“Type-C”或“SS49E”名称直接替换。

## 电流预算与走线

保留 32 颗键灯，删除 Logo 灯。采用每色约 12mA 的 WS2812B-4020 型号预算时，32 颗全白约 1.152A，加上霍尔和静态电流，整板约 1.5A。正常 8～12 键同时全白仍约为 0.64～0.78A。

电源的 3A 标称能力用于提供余量，不代表本 PCB 已验证可连续输出或消耗 3A。供电入口延续原板约 0.6～0.8mm 走线，输入通过保险丝进入既有灯光/霍尔供电干线。32 键单灯、上述器件电流是本版的负载前提；若换成每色 20mA 灯珠，或恢复双灯，需要重新评估保险丝、干线压降和温升。

没有直接增加数百微法的输入电容，以免未经控制地增大 Type-C 插拔浪涌。C69 配合每键已有去耦电容使用；若样机仍有明显压降/闪灯，应先核对电源及线材，再评估软启动和储能电容。

## ADC 分压已经修改

```text
ADG732 D 输出 ── R1 10kΩ ──┬── U1.11 / U1.12：ADC_OUT
                          │
                       R2 2kΩ
                          │
                         GND
```

分压比例为 1/6，5V 输入对应约 0.833V。按电源上浮至 5.25V、两个电阻最不利 1% 公差计算，最大约 0.890V，适合为 Tang 片内 SAR ADC 的 0～1V 单端量程预留正常工作余量。此计算不代表误接高电压、静电或上电尖峰保护。

U1.11 与 U1.12 本来就是同一个节点，只选一个接 ADC，另一个不能接独立数字输出。Tang 端必须选择支持 SAR ADC 的引脚并正确配置单端输入和参考地。每次切换 ADG732 通道后，需要等待外部模拟链路稳定，并满足 SAR ADC 采样保持时间；不能把分压电阻改好等同于整个 FPGA ADC 移植完成。后续应重新校准各键静态值和按压范围。
